# BIBIMBAP 100과제 점검 결과 요약 (2026-10-09)

점검 기준은 BIM-Edit과 같은 4가지 중 ①만점 답안 검사, ②정답 검사(조회 과제의 정답 키), ③대상 ID 검사.

**조건:** 채점 코드는 공개 저장소 github.com/nbharathik/bibimbap 커밋 `667004e`(2026-04-07)를 그대로 썼고, 저장소가 지정한 IfcOpenShell **0.8.3.post2**로 채점했다. 0.9.0으로 돌리면 충돌 검사 단계가 오류를 내서 거의 모든 편집 과제가 0점이 되므로 쓰면 안 된다. IFC 파일은 삭제 과제만 Hugging Face 최신본이고, 나머지는 같은 저장소 커밋 `a0291d6`(3/13)의 파일이다. 문제가 나온 과제의 파일은 HF 최신본과 내용이 같음을 확인했다(아래).

## 한눈에

| 과제 유형 | 과제 수 | 정답을 넣으면 만점? | 걸린 것 |
|---|---|---|---|
| 삭제 | 15 | **0 / 15** (깔끔한 삭제, 평균 40%) | 무결성 조건끼리 충돌(문·벽 6과제는 어떤 답도 만점 불가), 창 ID 없음 2, "사라짐" 항목 미사용 1 |
| 수정 | 15 | 11 / 15 | 회전 각도를 사각형 대각선으로 재서 정확한 45° 회전이 39.2°로 측정(geometry_12), 한쪽만 늘리라는데 중심 고정 요구 2(geometry_14, topological_12), 방향 해석 1(test_12) |
| 생성 | 15 | 14 / 15 | 방을 층에 붙이는 표준 방식(집합 관계)을 인정 안 함(geometry_04). 문틀 있는 문이 제 개구부와 "충돌" 처리되는 등 맞는 변형답 감점 3 |
| 조회(계산·위상) | 35 | 정답 키 28개 맞음 | **부피를 묻는데 정답 키가 면적 3개**(numeric_16·17·19), 해석이 갈리는 키 3, 단위 오기 1("둘레를 세제곱미터로") |
| 조회(개념) | 20 | 판단 보류(주관적) | **정답 키 ID가 파일에 없음 1**(conceptual_12), 복수 질문에 단수 답 형식 1 |

정리하면 100과제 중 **정답을 내도 만점을 못 받거나 정답 키가 틀린 과제가 24개**: 삭제 15(전부) + 수정 4(이 중 test_12는 질문 해석 문제) + 생성 1 + 부피·면적 오답 키 3 + 없는 ID 정답 1. 해석이 갈리는 조회 키 3개와 주관적인 개념 과제는 세지 않았다.

## 기준 ④ 독립 확인: 틀린 답이 높은 점수를 받는가 (추가, 10/9)
편집 과제 45개에 틀린 답 401개를 넣어 채점: **36개 과제에서 틀린 답이 0.9점 이상**(34개 과제에서 만점). 예: 기둥을 공중에 만들어도 만점(test_04), 삭제하라는 기둥을 그대로 두고 ID만 바꿔도 만점(test_16, 깔끔한 삭제는 0.5). 원인은 무결성 검사가 다른 객체의 형상과 새 객체를 보지 않고, 이동을 형상이 아니라 배치 값으로 재기 때문. 세부 `wrong-answers.md`.

## 대표 사례 (논문에 쓰기 좋은 것)
1. **삭제: 깔끔하게 지울수록 감점.** 표준 함수로 지우면 만점 0/15, 찌꺼기를 남기면 6/15 만점. (`../bibimbap-c1.md`)
2. **부피 문제의 정답이 면적.** numeric_16 "슬래브 개구부 부피": 개구부 2.4×1.5 m, 2.9×0.75 m, 두께 0.3 m → 부피 1.7325 m³인데 정답 키 5.775 = 두 개구부 면적의 합(3.6 + 2.175 m²). 직접 재계산해 확인. (`retrieve-check.md`)
3. **정확한 45° 회전이 39.2°로 측정.** geometry_12: 벽 배치 각도 90°→135°(정확히 +45°)인데 채점 코드는 가장 먼 두 꼭짓점(벽 사각형의 대각선)으로 방향을 재서 92.9°→132.1°로 읽음. 허용오차 1°라 탈락. 직접 재채점해 확인. (`update-c1.md`)
4. **벽을 기둥에서 떼어야 만점.** topological_12 "벽을 1 m 줄여라": 기둥에 붙은 끝은 두고 자유단을 1 m 자르면 0.67, 양끝을 0.5 m씩 잘라 기둥과 0.5 m 틈이 생기는 답만 1.0. (`update-c1.md`)
5. **정답이 파일에 없는 문제.** conceptual_12 "더 밝아 보이는 방": 파일에 방 2개뿐인데 정답 키 ID는 어느 것도 아님.

## 최신본 확인 (완료, 10/9)
문제가 나온 과제의 IFC 11개(02_00_012, 01_01_004·008·012·014, 01_02_012, 01_03_007·010·016·017·019)를 Hugging Face 최신본으로 받아 비교했다. 줄바꿈(CRLF)만 빼면 11개 모두 3월 저장소본과 **내용이 완전히 같다**(md5 일치). 정답 키는 채점 코드에 있으므로 위 결과는 최신 공개본에도 그대로 적용된다. 삭제 15과제는 최신본으로 직접 재채점해 같은 결과를 얻었다.
