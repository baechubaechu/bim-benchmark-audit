# BIBIMBAP 삭제 과제에 기준 ① "만점 답안 검사" 적용

작성: 2026-10-09

> **2026-10-09 갱신: 현재 Hugging Face 공개 데이터로 재실행해 결과가 똑같이 나와 확정.** HF에서 받은 파일로 돌렸고, 결과는 `bibimbap_c1_result_hf.json`. 파일 체크섬은 3월 저장소본과 다르지만(받은 파일은 CRLF 줄바꿈), 삭제 문제 문장 15개와 채점 결과는 동일.

> **2026-10-09 정정 (채점 라이브러리 버전):** BIBIMBAP은 IfcOpenShell **0.8.3**을 지정한다(`requirements.txt`). 처음 결과는 0.9.0으로 채점한 것이었다. 같은 답안 파일을 지정 버전 0.8.3으로 다시 채점한 것이 아래 표다(`bibimbap_c1_score_ifcos083.json`, 채점 스크립트 `bibimbap_c1_score.py`). 바뀐 점은 방 삭제 2과제뿐이다. 0.9.0에서는 채점 코드가 오류로 멈췄지만 0.8.3에서는 정상 채점된다. 나머지 13과제는 두 버전 점수가 같다.

## 무엇을 했나
- 대상: BIBIMBAP(Kujat 외, EC3 2026) 삭제 과제 15개 (basic 5, geometry 5, topological 5)
- 채점 코드: 공개 저장소 github.com/nbharathik/bibimbap 최신 커밋 `667004e` (2026-04-07)의 `data/tests/*.py`를 그대로 사용
- IFC·문제 파일: Hugging Face(clemenskujat/bibimbap-data)는 이 환경에서 접속이 막혀 있어, 같은 저장소의 **이전 커밋 `a0291d6` (2026-03-13)** 에 들어 있던 `data/ifc`, `data/prompts/all_questions.csv`를 사용. 이후 데이터는 Hugging Face로 옮겨졌고(3/17 커밋), **현재 공개본과 다를 수 있음**
- 만든 답안 3종
  - A: IfcOpenShell 표준 함수 `root.remove_product`로 대상만 삭제 (사람이 Bonsai 등에서 지우는 것과 같은 깔끔한 삭제)
  - B: A + 문·창의 개구부(opening)와 벽 연결 관계까지 삭제 (채점 코드의 "무결성" 하위 조건이 요구하는 것)
  - C: 대상 개체 한 줄만 지우고 그 개체의 속성세트·관계는 남겨 둠 (찌꺼기가 남는 지저분한 삭제, 비교용)
- 코드: `audit/bibimbap_c1.py`(답안 생성, 0.9.0), `audit/bibimbap_c1_score.py`(채점), 원자료: `audit/bibimbap_c1_score_ifcos083.json`(주결과), `bibimbap_c1_result*.json`(0.9.0 채점)

## 결과

| 답안 | 만점(1.0) 과제 수 | 평균 점수 |
|---|---|---|
| A 깔끔한 삭제 | **0 / 15** | 40.0% |
| B 깔끔한 삭제 + 개구부·연결 정리 | **0 / 15** | 40.0% |
| C 찌꺼기 남기는 삭제 | 6 / 15 | 63.3% |

(IfcOpenShell 0.8.3 기준. 0.9.0으로 채점하면 A·B 33.3%, C 4/15·50.0%)

→ **깔끔하게 지울수록 점수가 낮다.** BIM-Edit의 "잘 지우면 감점"과 같은 방향의 문제가 BIBIMBAP에도 있다.

## 왜 그런가 (채점 코드 기준)
삭제 점수 = (대상이 사라졌나) + (무결성 통과) 의 평균. 무결성은 두 조건을 **동시에** 요구한다.
1. 대상과 묶인 개구부·벽 연결·집합 관계는 지워져 있어야 함 (`delete_integrity.py`)
2. 대상 GUID를 뺀 **원본의 모든 IfcRoot**(속성세트, 관계 개체 포함)가 그대로 남아 있어야 함 (`integrity_utils.non_target_elements_unchanged`)

- 문 2과제(test_17, geometry_16), 벽 4과제(test_19, geometry_17·20, topological_16): 1번이 지우라는 개구부·벽 연결 관계도 IfcRoot이므로 2번에 걸린다. **어떤 답안도 무결성을 통과할 수 없다** (최대 0.5점).
- 기둥·개구부·방 과제들: 표준 삭제는 대상의 속성세트·관계도 함께 지우므로 2번에 걸린다. 찌꺼기를 남긴 C만 통과.

## 그 밖에 걸린 것 (기준 ③ 대상 ID 검사에 해당)
- ~~방 삭제 2과제는 제대로 지우면 채점 코드가 오류로 멈춰 0점~~ → **철회.** IfcOpenShell 0.9.0에서만 생기는 현상이었다. 지정 버전 0.8.3에서는 정상 채점된다(깔끔한 삭제 0.5, 찌꺼기 삭제 1.0).
- **topological_20**: 채점 코드가 "대상이 사라졌나" 항목을 한 번도 True로 바꾸지 않는다(`_is_deleted` 함수를 정의만 하고 안 씀). 어떤 답이든 최대 0.5.
- **geometry_18, geometry_19**: 채점 코드에 적힌 창 GUID 일부가 IFC 파일에 없다(6개 중 4개, 2개 중 1개). 현재 HF 데이터에서도 같아 **확정.** 대상을 지우면 채점이 오류로 멈춰 0점(0.8.3에서도 같음).

## 공개 논문 숫자와의 관계 (추정)
논문 표 3의 삭제 점수는 18.9~43.3%로 모두 50% 아래다. 우리 계산(0.8.3)으로 깔끔한 삭제의 상한은 40.0%, 지저분한 삭제의 상한은 63.3%이므로, 43.3%(GPT-5 Mini)처럼 40%를 넘는 점수는 깔끔하지 않은 삭제에서 나왔을 가능성이 있다. **모델 출력 파일을 보지 않은 추정**이다.
